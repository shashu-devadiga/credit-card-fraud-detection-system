# Credit Card Fraud Detection System

## Project Overview

The Credit Card Fraud Detection System is a machine learning-based application designed to identify potentially fraudulent credit card transactions.

The project integrates a trained machine learning model with a web application to predict whether a transaction is legitimate or fraudulent.

## Features

* Machine learning-based fraud prediction
* Web-based user interface
* Transaction details input
* Fraudulent and legitimate transaction classification
* Integration with a trained machine learning model

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Flask
* HTML
* CSS
* JavaScript

## Installation and Setup

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/credit-card-fraud-detection-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd credit-card-fraud-detection-system
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open the local address displayed in the terminal in your web browser.

## Machine Learning

The system uses a trained machine learning model to classify transactions based on the input features. The application loads the required model and preprocessing artifacts to generate predictions.

## Disclaimer

This project is intended for educational and demonstration purposes. Predictions should not be treated as a guarantee that a transaction is fraudulent or legitimate.
